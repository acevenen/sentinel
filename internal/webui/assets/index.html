Point Sentinel at a project

The fastest path from “I found an endpoint” to a submittable report. Five steps.

1

Capture your two test accounts

Open your browser DevTools → Network tab, browse the target as account A, then Save all as HAR. Repeat as account B. (Burp Suite's HAR export works too.)

2

Import the captures

Drop each HAR into Hunt → Import. Sentinel keeps read-only requests whose path has an ID, turns /orders/1001 into /orders/{id}, and records which objects each account owns.

3

Confirm scope

Review the generated manifest. Every request is checked against in_scope / out_of_scope before it is sent — out-of-scope is refused. This is what keeps you inside the program's rules.

4

Add your session tokens

Paste each test account's session token into the run panel. Tokens live only in memory for the run — never written to the manifest or to disk.

5

Dry-run, then run

Dry-run shows every request and its scope decision without sending anything. Then Run performs the cross-account test and produces a HackerOne-ready report for each finding.
